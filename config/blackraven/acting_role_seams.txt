# 黑羽鸦扮演覆盖层：固定版本提供方 jar 中已归类的可伪装职业判定点。
#
# Checked by `./gradlew verifyBlackRavenActingRoleSeams` (a dependency of verifyArchitecture) against
# libs/wathe-*.jar and libs/noellesroles-*.jar. Any unlisted site, vanished site, count change, or isRole call
# whose role operand is not an immediately preceding GETSTATIC of a Role field fails the build.
#
# Format: <TAG> <kind> <role id> <owner#method> <count>
# kind: isRole (reached by the overlay) | getAllWithRole | equals | idEquals | acmp (all stay raw)
# isRole tags (overlay reaches them; each must be safe to widen for the Raven's own UUID only):
#   SELF                the acting player's own skill, shop, item, tick, or voice-speaker gate
#   RECIPIENT           a sync / voice / packet gate that asks whether the Raven should receive something
#   LOCAL               a client check on the local viewer (HUD, instinct, key dispatch, money)
#   DEATH               runs after markPlayerDead, so the overlay's dead check keeps it raw
#   BEFORE              runs in the KillPlayer.BEFORE window, where the victim is not yet dead (none today)
#   TARGET_SERVER_ONLY  a server-side check on another entity that only matches ServerPlayerEntity targets
# raw tags (the overlay never reaches them; an adapter replicates the effect):
#   GAP_KIT             RoleAssigned starting kit (role.equals)
#   GAP_TASK_MONEY      TaskComplete money (getRole().equals)
#   GAP_DOOR_NOTICE     Engineer door notices (getAllWithRole)
#
# When a provider jar is bumped, re-classify every reported site before updating this list.
# 升级提供方 jar 时，必须先重新归类每个被报告的调用点，再更新本清单。
