# 大魔女重做方案（2026-09-11）

状态：用户已授权实施。按下述规则和注明的默认值实现；实施中补充：职业/道具护盾可穿透，词条类保护（包括背水一战、绝处逢生）不在穿透范围内。保留当前工作区所有已有修改，不进行无关重构。

## 一、已确认规则

### 仪礼剑

- 移除旧临时大招；完成两个任务获得仪礼剑。
- 攻击速度为 2。
- 持有时移动速度 +40%；具体持有槽位见建议默认值。
- 成功击杀后进入 30 秒击杀冷却。
- 保留右键冲刺。击杀冷却中可以冲刺，但撞人不能击杀。
- 左键和冲刺接触共用击杀冷却，位移冷却与击杀冷却独立，UI 必须区分。
- 无视职业与道具护盾，包括职业格挡、守护天使和 NoellesRoles 的其他护盾。背水一战、绝处逢生等词条类保护不在穿透范围内，保留原行为。
- 护盾/消耗品仍按原机制消耗，反杀仍生效。持有有效反杀保护的巫女被剑击杀后，大魔女仍可被反杀，双方死亡。
- 保留旧大招 BGM 音频文件；不必继续播放。

### 一技能：魔女因子

- 使用 NoellesRoles 技能键，免费，传播成功后冷却 20 秒。
- 范围内准心选中玩家，传播因子。
- 最多同时传播给总人数 / 5 名玩家；取整、人口快照等见建议默认值。
- 每个因子每 30 秒给予大魔女 25 魔力；持有者为预备魔女时 40，杀意魔女时 60。
- 持有者有理智系统时，每 60 秒减少 10 点理智；预备魔女减少 30 点。
- 被其他玩家击杀后，因子转移给凶手。
- 被大魔女或共犯杀死后，因子被回收。
- 持有者在大魔女和共犯本能透视中显示红色。

### 二技能：招募同伙

- 免费，完成两个任务后解锁，不需要冷却。
- 使用独立第二技能键；建议沿用 Witch 现有默认 N 的按键。
- 范围内准心选中任意存活身份，强制转换成共犯。
- 共犯不再自然分配；名额沿用旧公式：N < 18 时为 0，否则 floor((N - 18) / 6)。
- 按累计成功招募人数扣除名额，死亡不补名额。
- 仅保留钥匙、万能钥匙、左轮手枪和信件；食物、饮品也清理。
- 清理物品按商店售价折算，没有售价的按每件 25 金币折算。
- 原有金币保留，最终金币 = 转职前金币 + 清理物品折算额。
- 新身份商店购买次数限制重新初始化，不沿用旧身份限购记录。

## 二、跨项目核对发现

已核对 SparkWitch、wathe、NoellesRoles、SparkAssist、SparkFactionAPI、SparkStrength、SparkTraits 的相关源码。

### 商店与身份转换

- 没有通用的物品售价注册表；wathe 通过玩家和身份构建商店。
- 同一物品售价可能不同，例如普通杀手手雷 350、爆破手 300；SparkTraits 魅力特质还能改变有效售价。
- 商店有多件装、随机产物、自定义购买处理和纯技能条目，不能把显示图标直接当成出售物品。
- NOTE 与 LETTER 是不同物品；保留信件不等于保留可购买的便条。NoellesRoles 有两种万能钥匙身份。
- wathe PlayerShopComponent.initializeShop 清理并重建限购和商店冷却，不清空余额；reset 会清空余额，不能直接使用。
- 共犯原有身份初始化会设置初始金币；招募流程必须保证最终余额仍严格等于旧余额加折算额。
- addRole 只改身份映射，不能自动完成旧能力退出、商店初始化、阵营状态及客户端同步。
- 任意身份转职需要处理饕餮吞人、灵体投射、独立特质状态等跨模组运行状态，不只是换职业 ID。

### 战斗与 UI

- 仪礼剑左右键最终汇聚到 CeremonialSwordCombatService.killWithCeremonialSword，应在此统一校验击杀冷却。
- 现有冲刺使用 Minecraft 物品冷却管理器，时长 100 tick（5 秒）；新 30 秒击杀冷却不得占用同一计时器。
- 攻击速度 2 是第三个独立概念：原版攻击蓄力，不等于冲刺或击杀冷却。
- wathe 的 KillPlayer.BEFORE 遇到首个非空结果即停止。force=true 或提前 allow() 都不能保证后续护盾消耗和反击执行。
- 应对仪礼剑单独区分“触发保护的消耗/反击”与“是否取消死亡”，不全局关闭防护监听。
- NoellesRoles 单个监听内部也存在提前返回，需检查多重保护的分支，不只修改外层返回值。
- 托法娜当前消费与反杀入队逻辑可以与死亡取消拆开；队列不要求原持有者仍存活，可支持双方死亡。反杀本身不得继承仪礼剑穿盾上下文。
- SparkTraits 的格挡、背水一战、绝处逢生与抑郁假死属于词条机制，不修改、不穿透；继续通过现有公共门面遵守词条返回结果。
- SparkFactionAPI 直接注入仪礼剑方法，签名修改会影响兼容；合法目标/阵营影响规则不能当成护盾一并删除。
- wathe 通用冷却数字读取手持物品冷却，目前对仪礼剑表示冲刺。需避免与新 UI 叠出两个含义不明的数字。
- SparkAssist 有旧仪礼剑技能指南及翻译覆盖，需同步更新。
- SparkStrength 有死亡流程上的尸体信息处理；必须保留正常死亡、掉落、记录及 AFTER 流程。

### 版本限制

本地 _sources 源码为 wathe 1.5.7 / NoellesRoles 1.7.7，而 SparkWitch 构建锁定的 libs 依赖为 wathe 1.5.6 / NoellesRoles 1.7.6。上述是源码合同调查，不代表所有注入位置已在依赖 JAR 上验证。实施前应核对实际锁定 JAR，不能未经授权顺带升级版本。

## 三、实施采用的默认值

- 施法范围 8 格，要求视线无遮挡；服务端重新校验目标。无目标/无效目标不扣冷却或名额。
- 两任务奖励为常驻剑，优先替换原小刀，确保只发一次。
- 移速在主手或副手持剑时生效，两手同时持有只加一次 40%；两手均不再持有时撤销。使用玩家级临时属性统一维护，不残留速度药水效果。
- 保留现有冲刺 5 秒位移冷却和遇到玩家停止的移动行为；只改变能否击杀。
- 攻击速度实际约束左键蓄力，不只修改显示值。
- 因子上限取开局参赛人数 floor(N / 5)，单人不叠加因子。
- 因子收益/理智计时从施放开始，转移保留进度；结算按当前身份。
- 环境死亡、凶手无效或已有因子时回收；招募因子持有者后回收，回收不额外赠送魔力。
- 仅同步必要的因子可见信息；红色不额外突破原有本能隐藏规则。
- 不允许招募自己或已经是共犯的人，不浪费名额；不加职业类别白名单。
- 价格采用转职前目标实际商店的有效金币售价（包含既有折扣），找不到已识别的物理产物时每件 25。这是当前商店查询口径，不代表跨所有身份搜集历史原价。
- 多件装按单件价值折算，对同种物品汇总后向下取整；随机商品需按真实产物建立适配，不以图标推断；纯技能条目不当成物品售价。
- 明确售价为 0 的条目仍属于有售价，不使用 25 兜底。魔力售价不能未经定义直接当金币价。
- 原自然回魔、击杀回魔及商店法术暂不改动；特质是否保留/重分配需遵循实际角色转换兼容合同，不能直接全量清空玩家状态。

## 四、实施顺序

1. **兼容基线与规则测试**：核对锁定 JAR；建立角色商品、实际产物、折扣、限购、护盾和旧能力退出清单；确定价格查询范围。
2. **两任务进度及剑常驻化**：第二次任务同时获得剑、解锁招募；停止旧大招注册和临时换刀流程，保留 BGM 资源。
3. **独立剑战斗状态**：服务器权威的 30 秒击杀冷却、原冲刺计时、2 攻速及持剑移速；物品切换不重置击杀冷却。
4. **防护副作用兼容**：逐个接入护盾消耗、格挡副作用和反杀，保持普通武器路径不变；延迟反杀不得受原剑攻击上下文污染。
5. **魔女因子**：传播、容量、周期收益、理智扣除、真实死亡后的转移与回收、身份变更与局结束清理。
6. **招募事务**：先快照旧金币、物品和有效商店价格，再清理旧身份状态、变更身份、处理库存、初始化新商店限购，最终恢复旧金币加折算额并同步；防止重入与重复结算。
7. **客户端及文案**：一技能/二技能独立显示；仪礼剑分别显示“击杀：就绪/剩余秒数”和“冲刺：就绪/剩余秒数”；同步 SparkAssist 指南、技能面板与中英文本。
8. **验证**：Java 21 下运行项目规定的 test、verifyArchitecture、compileJava、compileClientJava 与完整顺序 build；有修改的关联项目分别按自身入口验证。多人实测后再评估数值平衡。

## 五、主要验收用例

- 任务 0/1/2 的剑和招募状态正确；重复任务不重复发剑。
- 招募免费、无冷却；18～23 人局无名额，24～29 人局一个名额；已招募者死亡不补。
- 所有存活职业均可成为目标；旧技能/吞人/投射等状态正确退出。
- 保留物品不删除；饮食删除；未知物品按 25；折扣、多件装、随机产物与限购处理符合最终定价口径。
- 旧余额不会被共犯初始金币覆盖；不会重复发退款；新商店限购恢复。
- 左键杀人后冲刺仍可用但不能杀人；冲刺杀人后左键也进入 30 秒冷却；接触时重新判断冷却。
- 击杀冷却中的攻击不退回原版伤害、不消费对方护盾、不触发反杀。
- 单层和组合护盾正常消耗但目标死亡一次；格挡副作用保留。
- 有反杀保护的巫女死亡后，延迟反杀仍作用于大魔女；不重复发死亡奖励。
- 普通武器和其他角色防护不变；正常尸体、掉落、回放及跨模组死亡事件保留。
- 因子普通/预备/杀意收益及理智周期正确，转移不复制；无效凶手不占死名额。
- 同时显示击杀和冲刺状态，不和 wathe 原有数字重复；装/不装 SparkAssist 均无旧大招说明误导。
- BGM 音频仍在资源目录，不误删。
